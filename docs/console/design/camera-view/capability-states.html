Acknowledged with no card in the camera. The key stays, because it will work the moment a card is in — but it never turns green on the acknowledgement alone.

Absent means gone. No greyed row, no disabled control, no explanation — a fixed camera simply has no Aim group, and a camera with no recorder has no Record key on the rail. Anything else trains an operator to read grey as "not now" when it means "not ever".

Advertised-but-not-answered is amber and dashed, and it always carries the reason. Amber rather than grey because it is a fault, not an absence — something is lying to us, and on a different firmware or a different kernel it may start working. Dashed because it must never be mistaken for a control you can reach. And the reason line is not decoration: fifteen values sent, every one acknowledged, the frame stayed 720p is the difference between a defect somebody can act on and a mystery.

The soft key is the interesting one. It stays on the rail rather than disappearing, because no card is a condition that changes when you put a card in — so the key is real, the annunciator carries the truth, and an acknowledgement never turns the indicator green on its own.
