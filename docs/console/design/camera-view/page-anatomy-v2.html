The biggest possible picture, and the closest to a real display head. The cost is that the panel covers the right of the frame while you are using it — so on a camera you are aiming, the panel hides the part of the shot you are aiming at. It also needs a mode per panel, and R‑UI‑12 already requires a page that hides part of itself to be captured in each of those parts, so this multiplies what the build gate has to photograph on every commit.

Everything here is placeholder content in the real palette, drawn to scale — the readouts, the amber commanded‑versus‑actual marks and the soft keys are there so you can judge weight and density, not to fix any particular control.
