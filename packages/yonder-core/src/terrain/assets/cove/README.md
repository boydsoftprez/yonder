# Cove terrain and mapped surface

Derived from USGS 3D Elevation Program public-domain data. Survey: **2016-02-05 through 2016-04-04**. Product identifiers, URLs, actual input hashes and inspected coordinate references are in `manifest.json`.

This pack contains one metre bare-earth elevation and a separate maximum-return LiDAR surface. Sources are the `x28y399` DEM and `2738597NE` / `2738597SE` point-cloud tiles. Building class 6 is present; vegetation classes are absent. Unclassified elevated returns are retained without pretending to classify trees. The observed surface has holes and is a 2016 snapshot, not a current complete obstacle inventory.

Source inspection identified isolated unclassified returns hundreds of metres above their neighbors. A declared preparation heuristic masks cells more than **80 m above DTM and 30 m above every observed neighboring sample within a 2 m radius**. At least one observed neighbor is required. The 28 masked cells remain **unknown surface**; they are never replaced by ground or a lower inferred obstacle. A real isolated structure could also meet this heuristic, so masking does not establish obstacle-free terrain. `preparation-report.json` preserves their raw NAVD88 maxima, locations, neighbor/ground heights, criteria and counts. Surface coverage changes from 97.692755% observed to 97.691739% screened; DTM coverage remains 100%. Missing support propagates into coarse levels and advisories.

Heights are metres in **EGM96**, transformed from native NAVD88/GEOID12B using the hash-checked NOAA CONUS `us_noaa_g2012bu0.tif` and NGA `us_nga_egm96_15.tif` grids. `preparation-report.json` records the explicit pipeline, independent interpolation control points and inverse residuals. NOAA and NGA grid metadata identify their data as public domain. Numeric datum conversion does not validate GNSS accuracy, camera calibration or capture-time alignment. A generic MSL telemetry label alone is insufficient to establish compatibility.

Native one metre sample spacing does not imply one metre absolute horizontal accuracy. Coarser visual levels preserve maxima only where their source support is complete. Outside the pack or in missing cells, elevation remains unknown. No flight command is generated by this data.

Reproduction, cache limits, file format, processing rules, dependency notices and tests: `scripts/terrain/README.md` at the repository root. The runtime manifest is authoritative for dimensions and file hashes.
